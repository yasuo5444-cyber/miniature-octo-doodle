# Lowpoly Racer v3

친구와 최대 4명이 즐기는 로우폴리 온라인 레이싱. Three.js(클라이언트) + Node.js/WebSocket(서버) 단일 서비스.

## 실행
```bash
npm install
npm start          # http://localhost:3000
```
Render/Railway 등에 `npm install` / `npm start` 로 배포하면 그대로 동작합니다 (`PORT` 환경변수 자동 인식).

## 조작
| 키 | 기능 |
|---|---|
| W / ↑ | 가속 |
| S / ↓ | 브레이크 · 후진 |
| A / D, ← / → | 조향 |
| **Shift** | 드리프트 (횡슬립 중 니트로 충전) |
| **Ctrl** | 니트로 |
| C | 카메라 전환 (체이스 / 원거리 / 후드) |
| R | 트랙 복귀 (속도 0으로 리셋) |
| M | 음소거 |

> ⚠ **Ctrl+W 는 브라우저가 탭을 닫습니다.** 니트로를 자주 쓰면 방향키(↑↓←→) 조작을 권장합니다.
> 모바일은 화면에 가상 버튼이 자동으로 표시됩니다.

## 맵
| 맵 | 난이도 | 특징 |
|---|---|---|
| 🌇 선셋 서킷 | ★ | 평지, 완만한 코너, 약 980m |
| ⚓ 하버 GP | ★★ | 대형, 긴 직선 + 시케인, 항만 다리, 약 1,650m |
| ⛰️ 마운틴 패스 | ★★★ | 최대 고도 36m 오르막/내리막, 헤어핀, 점프 1개, 약 1,750m |
| 🏜️ 캐니언 스파이럴 | ★★★★ | 대형, 급경사, 내리막 직후 급코너, 점프 2개, 약 1,850m |
| 🎲 랜덤 트랙 | 가변 | 시드 기반 생성, 완만한 언덕. 호스트가 "새 트랙 뽑기" 가능 |

호스트가 로비에서 맵 카드를 클릭해 선택하며, 모든 참가자에게 미리보기가 동기화됩니다.
경기 후 **같은 맵 재경기** 또는 **로비로 (다른 맵 선택)** — 방과 멤버는 유지됩니다.

### 새 맵 추가하기
`public/maps.js` 의 블록 하나를 복사해 수정하면 됩니다.
- `pts`: `[x, z, 고도]` 제어점 (닫힌 스플라인). 인접하지 않은 구간은 30m 이상 떨어뜨리고, 코너 최소 반경은 13m 이상을 권장.
- `jumps`: `{ pt: 제어점 인덱스, len: 램프 길이, h: 램프 높이 }` — 그 제어점에서 도로가 뚝 떨어지는 점프대. 착지 지점 뒤로 60m 이상 직선 확보.
- `pads`: 부스트 패드 위치(트랙 진행률 0~1).
- `cp`: 체크포인트 수. **`server.js` 의 `MAP_CP` 에도 같은 값을 추가**해야 합니다. `MAP_ORDER` 에 id 추가.

## 고도 시스템
- 오르막은 감속, 내리막은 가속 (`P.gravity`).
- 차체 피치가 노면 경사를 따라가고, 카메라는 언덕 뒤에서 땅에 묻히지 않도록 지면 위로 보정.
- 램프 끝이나 급한 정점을 빠르게 넘으면 자연스럽게 이륙 → 공중에서는 조향·가속 거의 불가, 착지 충격 시 감속·카메라 흔들림.
- 도로 옆 경사 둑(embankment)이 지면까지 이어져 고가 느낌을 냅니다. 둑 위로 떨어져도 주행 가능(잔디 감속).

## 서버 검증
- 각 맵의 체크포인트를 **순서대로** 통과해야 랩 인정 (지름길·역주행 무효, 랙 보정으로 1개 건너뜀은 허용).
- 완주 순서·기록·베스트 랩은 서버가 확정. 1등 완주 후 60초가 지나면 나머지는 DNF.

## 튜닝
`public/main.js` 상단 `P` 객체: 최고속(`maxSpeed`), 가속(`accel`), 그립/드리프트 그립(`grip`/`driftGrip`), 조향(`steer`), 니트로(`nitroSpeed`, `nitroUse`, `nitroCharge`), 중력(`gravity`).
카메라 거리/높이는 `camModes`.

## 저사양
그림자 없음, 픽셀비 1, 안티앨리어싱 off, Lambert 플랫 셰이딩, 트랙 전체가 드로우콜 1개 + 장식은 InstancedMesh.
로비의 **그래픽: 낮음**은 해상도 70%, 장식 45%, 포그 근접.

## 참고
- Three.js 는 CDN(importmap)에서 로드합니다. 오프라인이 필요하면 `three.module.js` 를 `public/` 에 두고 `index.html` 의 importmap 경로만 바꾸세요.
- 경기 중 새 참가자 입장은 불가(로비 상태에서만 입장). 새로고침하면 방에서 나가게 됩니다.
