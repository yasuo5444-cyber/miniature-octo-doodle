# LowPoly Racer — 4인 온라인 서킷 레이싱

Node.js(Express + ws) 서버 하나로 돌아가는 브라우저 레이싱 게임입니다.
설치 없이 링크로 초대하고, 6자리 방 코드로 최대 4명이 같은 트랙에서 경쟁합니다.

## 실행

```bash
npm install
npm start          # http://localhost:3000
```

친구와 하려면 서버를 외부에 배포하거나(Render / Railway / Fly.io 등, `npm start` 하나면 됨) 같은 네트워크에서 `http://<내IP>:3000` 으로 접속하면 됩니다.

## 플레이 흐름

1. 닉네임 입력 → **방 만들기** (호스트) / 방 코드 입력 → **참가**
2. 로비에서 **초대 링크 복사** → 친구에게 전달 (`?room=코드` 링크로 자동 입력)
3. 호스트: 랩 수(1/2/3/5) 선택, 🎲 새 트랙 (시드 기반 절차 생성, 로비 미리보기 + 3D 배경 미리보기)
4. 참가자 전원 준비 → 호스트 **경기 시작** → 3·2·1·GO
5. 결과 화면 → 호스트가 **같은 트랙 / 새 트랙 재경기** → 같은 방·같은 멤버로 로비 복귀

## 조작

| 키 | 동작 |
|---|---|
| W / ↑ | 가속 |
| S / ↓ | 브레이크 · 후진 |
| A D / ← → | 조향 |
| Shift | 드리프트 (횡슬립 중 **니트로 충전**) |
| Ctrl | 니트로 (최고속 +28%) |
| R | 트랙 중앙으로 복귀 (속도 0) |
| C | 카메라 (체이스 / 원거리 / 후드) |
| M | 음소거 |

> **주의:** 니트로가 Ctrl이므로 `Ctrl + W`를 누르면 브라우저 탭이 닫힐 수 있습니다(브라우저 예약 단축키라 차단 불가). 니트로를 자주 쓴다면 WASD 대신 **방향키(↑↓←→)** 조작을 권장합니다.


모바일(터치 기기)에서는 화면 하단에 가상 버튼이 자동으로 표시됩니다.

## 게임 디테일

- **절차 생성 서킷**: 시드 하나로 모든 클라이언트가 동일한 트랙 생성. 자기 교차·과급 코너 자동 검증. 연석(빨강/흰색), 차선, 벽, 체커 출발선, FINISH 아치, 관중석, 나무·건물(InstancedMesh).
- **차량 물리**: 속도 의존 조향, 헤딩/속도벡터 분리 방식 드리프트, 잔디 감속, 벽 반발 + 카메라 흔들림, 차량 간 충돌 밀어내기.
- **부스트 패드** 3개(트랙마다 위치 다름), **니트로 게이지**(드리프트로 충전).
- **HUD**: 속도계, 랩/순위, 현재·마지막·베스트 랩 타임, 실시간 순위표, 미니맵(전 차량 표시), 역주행 경고, 완주 피드, 핑.
- **서버 검증**: 체크포인트 12개를 순서대로 통과해야 랩 인정(건너뛰기·역주행 무시). 완주 순서·기록·베스트 랩은 서버가 확정. 1등 완주 후 45초 지나면 나머지는 DNF 처리.
- **사운드**: 에셋 없이 Web Audio 합성 (엔진 RPM, 스키드, 부스트, 카운트다운, 팡파르).
- **저사양 대응**: 그림자 없음, 픽셀비 1 고정, 안티앨리어싱 off, 드로우콜 ~20개. "낮음" 옵션은 해상도 70% + 장식 축소 + 포그 근접.

## 구조

```
server.js          방/플레이어/체크포인트/결과/재경기 (ws 릴레이 + 검증)
public/index.html  로비·HUD·결과 UI
public/style.css
public/main.js     렌더링, 카메라, 네트워크 보간(120ms 버퍼), HUD, 오디오, 입력
public/track.js    시드 기반 트랙 생성/지오메트리/미니맵/최근접 탐색
public/car.js      아케이드 차량 물리
```

Three.js 는 jsDelivr CDN(importmap)에서 불러옵니다. 오프라인 배포가 필요하면 `three.module.js` 를 `public/` 에 두고 importmap 경로만 바꾸면 됩니다.

## 튜닝 포인트

- `public/car.js` 상단 상수: `MAX_SPEED`, `ACCEL`, `TURN`, `GRIP`, `DRIFT_GRIP`
- `public/track.js`: `TRACK_WIDTH`(도로 폭), `CHECKPOINTS`(server.js 와 반드시 동일), `_generate` 안의 반지름/제어점 개수
- `server.js`: `FINISH_GRACE_MS`, 카운트다운 타이밍

## 알려진 제한

- 경기 중 새 참가자는 입장 불가(로비/결과 상태에서만 입장).
- 브라우저 새로고침 시 재접속(자리 유지)은 지원하지 않음 — 다시 방 코드로 입장해야 합니다.
- 차량 위치는 클라이언트가 시뮬레이션하고 서버는 진행도(체크포인트)만 검증하는 구조입니다. 친구끼리 즐기는 용도에 맞춘 설계이며, 치트 방지가 필요하면 서버 물리로 옮겨야 합니다.
